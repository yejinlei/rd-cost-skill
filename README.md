# RD Cost - 研发费用评估技能

研发费用评估、研发预算测算、项目研发成本分析的专业技能。

## 功能特性

- **研发费用评估** - 评估研发费用的合理性和合规性
- **研发预算测算** - 测算研发项目所需的总预算
- **项目研发成本分析** - 分析项目各阶段的成本构成
- **研发投资回报分析** - 计算ROI和评估投资价值
- **合规性检查** - 确保符合高企认定和加计扣除要求

## 安装

```bash
npx skills add yejinlei/rd-cost-skill --skill rd-cost
```

## 使用方法

提供项目基本信息，技能将自动计算研发费用：

```
项目类型：软件研发/硬件研发/AI算法研发/工艺技术研发
研发周期：X个月
研发人数：X人
人均月薪：X元
是否委外：是/否
委外金额：X元（如有）
风险等级：低/中/高
```

## 费用构成说明

### 1. 直接投入费用

**定义**：为研发活动直接消耗的材料、燃料、动力等费用。

**计算方式**：按项目类型乘以系数

| 项目类型 | 系数 | 包含内容 |
|---------|------|----------|
| 软件研发 | 10% | 设备折旧、软件许可、云服务、测试设备 |
| 硬件研发 | 35% | 原材料、样品、模具、检测设备 |
| AI算法研发 | 20% | 算力资源、数据采购、模型训练费用 |
| 工艺技术研发 | 25% | 试验材料、检测费用、工艺设备 |

**公式**：
```
直接投入 = 人力成本 × 类型系数
```

### 2. 间接分摊费用

**定义**：研发活动中必须分摊的公共成本。

**计算方式**：按人力成本的15%计算

**包含内容**：
- 办公场地分摊（研发人员使用的办公空间租金）
- 水电网络费用分摊
- 管理费用分摊（行政、人事、财务等职能部门支持）
- 办公设备折旧（电脑、办公家具等）
- 其他公共费用（保洁、安保、物业管理等）

**公式**：
```
间接费用 = 人力成本 × 15%
```

### 3. 委托外部研发费用

**定义**：委托其他机构或个人进行研发活动所发生的费用。

**计算方式**：直接使用用户提供的委外金额

**注意**：根据政策规定，委托外部研发费用的80%可计入研发费用加计扣除范围。

### 4. 风险准备金

**定义**：为应对项目不确定性预留的费用。

**计算方式**：按费用小计的一定比例计算

| 风险等级 | 缓冲比例 | 说明 |
|---------|---------|------|
| 低风险 | 5% | 技术成熟、风险可控的项目 |
| 中风险 | 10% | 一般研发项目 |
| 高风险 | 15% | 新技术、高不确定性项目 |

**公式**：
```
风险准备金 = (人力成本 + 直接投入 + 间接费用 + 委外费用) × 风险系数
```

## 计算公式

### 人员人工成本
```
人力成本 = 研发人数 × 研发周期(月) × 人均月薪
```

### 最终研发预算
```
总预算 = 人力成本 + 直接投入 + 间接费用 + 委外费用 + 风险准备金
```

## 示例

**输入：**
```
项目类型：AI算法研发
研发周期：3个月
研发人数：1.5人
人均月薪：25000元
是否委外：否
风险等级：中风险
```

**输出：**
```
人力成本 = 1.5 × 3 × 25,000 = 112,500元
直接投入 = 112,500 × 20% = 22,500元
间接费用 = 112,500 × 15% = 16,875元
费用小计 = 151,875元
风险准备金 = 151,875 × 10% = 15,188元
总预算 = 167,063元
```

## 合规性

输出符合以下政策要求：
- 《高新技术企业认定管理工作指引》
- 《研发费用加计扣除政策》

### 可归集费用范围
1. **人员人工费用**：研发人员工资薪金、五险一金
2. **直接投入费用**：材料、燃料、动力、模具、样品/样机
3. **折旧费用**：研发设备折旧（间接费用中包含）
4. **无形资产摊销**：软件、专利权摊销
5. **设计试验费**：新产品设计、工艺规程制定、临床试验
6. **委托外部研发**：委托其他机构研发的费用（80%计入）

### 不可归集费用
- 与研发无关的生产成本
- 销售费用、管理费用（除分摊部分）
- 资本化利息支出
